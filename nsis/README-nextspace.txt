NextSpace Classroom Management
Development build based on Veyon 4.11.4

This development build is intended for Windows classroom management over a
local wired or wireless network, including offline LAN use. Release and
classroom verification are still pending.

Applications
------------
NextSpace Teacher Console
NextSpace Student Agent
NextSpace Classroom Administration
